# 網頁設計規格

最後確認：2026-09-23。這是使用者逐次確認後的**現行設計基準**，不是待辦提案。
適用於 `include/web_ui.h` 的 Station 操作網頁；功能入口見 [function-entrypoints.md](function-entrypoints.md)。

## 修改原則

- 修改網頁前先讀本文件。使用者的新明確指示優先於本文件；已授權的修改直接完成並更新規格。
- 只改被要求的部分。不要以美化、簡化、重構或一致性為由，重排其他控制、恢復移除功能、改變操作門檻。
- 版面改動不能順便更改 Servo 指令方向、校正公式、GPS 追蹤條件、LoRa 協定或 SD 記錄行為。
- 如新需求與既有設計衝突，明確說明差異。不能靜默選另一種產品行為。
- 行為或介面異動同步更新本文件、`CHANGELOG.md` 及相關功能文件；保留測試與部署狀態。

## 畫面與視覺

1. 預設進入**雷達視圖**。只有雷達操作頁與資訊頁；沒有頂部「雷達／資訊」分頁列。
2. 雷達／地圖畫布使用完整可視高度，以 `visualViewport.height` 跟隨手機瀏覽器可見範圍。
   操作列、燈號、角度控制和提醒均覆蓋於畫布上，不另占頁頭或頁尾高度。
3. **白底**，深綠格線、方向字、路徑與波束。不得恢復深綠／黑底雷達。
   主要文字 `#11251a`、操作綠 `#076c38`；GPS 標籤為半透明白底深色文字。
4. 操作按鈕使用半透明白底，選取態為綠底白字。手機不得出現橫向溢出或提醒下方額外空白。
   頂部按鈕相對原版放大約 **1.5 倍**：字級 18 px、高度 46 px；窄螢幕只收緊水平 padding，仍維持單排。
   分段按鈕只有整組兩端圓角，中間按鈕四角為直角，接縫不得有缺口或獨立圓角。
5. 字體使用系統字體，頁面 UTF-8。不得出現中文亂碼。核心操作不依賴外部字體／CDN。

## 控制位置與順序

| 元素 | 固定規則 |
|---|---|
| 資訊 | 最左上角，獨立按鈕；與右側「雷達」相隔 **10 px** |
| 視圖 | 資訊右側，依序「雷達／地圖」 |
| 控制模式 | 右上角，依序 **「手動／GPS／UART」**；與左側按鈕同一排 |
| 資訊頁返回 | 資訊頁上方「← 返回雷達」 |
| 角度數字 | 寫在外圈的圓形把手內；不得恢復右下角數字框或底部水平滑桿 |
| 提醒 | 畫面底部半透明覆蓋層；見下節 |

資訊頁保留裝置遙測、韌體版本、校正偏移、回到 90°、指南針校正、共用 Servo 最高速度、GPS 預測 α，及下列 Station／Client 擴充卡。
沒有另外新增除錯或 SD log 操作 UI；SD 透過 USB 讀取。

### Station 手機位置與 T096 Client

- 資訊頁在既有 Servo／GPS 設定卡後，保留簡短的「Station 位置」卡：顯示目前來源、位置時間及精度；可切回 Station GNSS、由手機更新，或在無法開手機定位頁時手填緯度／經度／精度。手機通常放在 Station 旁邊，故可作為 Station 位置來源。
- Station 內嵌頁是 HTTP，不能宣稱可直接取得瀏覽器定位。使用者按「用手機更新位置」才開啟 GitHub Pages 的 HTTPS 手機定位頁 `phone-location.html`；它用 `watchPosition` 持續回傳。頁面背景化／鎖屏／被瀏覽器節電時可能停止，Station 只在 RAM 保留最後成功 snapshot 到重新開機，不能說成背景定位保證。
- 手機定位頁不會上傳位置；它只會回傳給本次開啟它的 Station 頁面。主頁只收固定 `https://n8886919.github.io` origin 與當次開啟頁面的有效位置。return URL 放於 fragment，避免傳到 GitHub HTTP 請求；僅可為 HTTP 私有 IP、localhost 或 `.local` Station 位址；手動輸入仍會走同一個 Station local API。
- 資訊頁另有「T096 Client 遠端控制」卡。僅在近期收到 T096 `STATE` 時啟用開始、停止為待命、無 GPS 的 LoRa RF 測試及深度休眠請求；送出後要顯示等待 Client 確認，不能把已入隊當成完成。停止後是可由 Web 最遲約 30 秒重新啟動的待命；未接 USB 時待命 12 小時會自動請求深度休眠，USB 供電時抑制。Client 回覆收納請求不證明已經睡眠；深度休眠後需外部喚醒，Web 不能喚醒，充電板上的實際休眠仍未驗證。USB 供電時禁用深度休眠請求並顯示先移除 USB。顯示 Client state、STATE 年齡、命令結果、RF 收／漏包、RSSI、SNR 與最大間隔。離線只顯示未收到近期 STATE，不可假稱待命或深度休眠；開始／停止 Client 也不能切換 Servo／GPS 模式。

## 雷達與地圖

- **零個、一個或兩個有效 GPS 都可選雷達**。定位消失不得強制切成地圖。
- 兩端有定位時雷達以 Station 為中心；只有 Station 時以 Station 為中心，只有 Client 時以 Client 為中心。
  無定位時保留格線與角度控制，不畫虛構的位置／相對距離。
- 地圖只用即時有效點決定中心：單端用該點，雙端用兩點中點。歷史軌跡不拉動地圖中心。
- 雷達以上方對應**校正偏移**旋轉；偏移 90° 時 E 在上、N 在左。位置、方向字、地理波束使用同一旋轉。
- 路徑只保留最近 5 分鐘；不新增期間文字、路徑圖例或其他已移除說明。
- 支援 pinch／wheel 縮放。地圖圖磚由瀏覽器取得；沒有圖磚仍可呈現位置、軌跡及比例尺。

## 上半圓角度控制

- 軌道與雷達最外圈同半徑，**永遠固定在畫面上半圓**：左 0°、正上方 90°、右 180°。
  地圖也採相同控制排列，不隨校正偏移或磁偏角旋轉。
- 手動模式顯示粗軌道、刻度及 **44 px 圓形把手**，把手內顯示角度並保留小握把線條。
- GPS／UART 模式**只隱藏軌道、刻度與握把線條，仍保留圓形角度標記**。
  標記顯示目前 `servo.angle` 換算的 UI 角度，不能拖曳，不因不可操作而把數字淡到難以辨識。
- 手動顯示待達目標，拖動時顯示本地預覽。**拖動不送出，放開才送出**。
  保留鍵盤方向鍵及既有 HTTP 排程、新鮮度檢查與模式隔離。
- pointercancel、失去 capture、第二觸點、切模式／視圖／頁面、尺寸變化都取消未完成手勢。
- UI 與內部角度維持 `raw = 180 - ui`。控制刻度不是地理方位；波束仍用
  `mount_offset + declination - raw` 計算。角度資料是命令值，不是實體 Servo 回授。
- 開機手動、Servo 90°，校正偏移預設 90° 並視為有效。**雷達可選不等於 GPS 追蹤可選**：
  GPS 模式維持雙端有效定位等後端條件；資訊頁重新校正仍要求 Servo 回到 90° 且停穩。

## 提醒覆蓋層

- 提醒存在時顯示，預設收合；收合列和展開面板均為半透明白底，讓下方雷達仍可見。
- 整區覆蓋在畫布底部，不能使畫布縮小、改變圓圈尺寸，也不能在底部加入額外留白。
- 展開按鈕醒目綠底白字：「▲ 展開提醒」／「▼ 收合提醒」，整列可點擊。
- 展開上緣按雷達下方 NESW 方位字所在圈附近安排；短螢幕保留可閱讀高度。
  壓縮方位圈與提醒之間的留白，優先放大圓圈；受高度限制時，下方方位字基線約距收合列上緣 3 px。
  過長清單在面板內捲動，不可向上無限制擋住整張雷達。地圖和資訊頁使用各自的可用高度限制。
- 提醒內容與門檻由後端提供；不要為了版面把警告吞掉或改成健康狀態。

## GPS／LoRa 紅綠燈

三個燈為**同一垂直群組**，由上而下固定：**Station GPS、Client GPS、LoRa**。
每項都有顯眼圓形燈、名稱與短狀態字，不只靠顏色傳達狀態。
LoRa 的狀態行顯示 `1.8 FPS · 10s` 形式的最近 10 秒平均；連線狀態保留於燈色、提示及可存取名稱。

| 燈號 | 綠 | 紅 |
|---|---|---|
| Station GPS | `/api/track.station.fix` 有效 | 無有效定位 |
| Client GPS | `/api/track.client.fix` 有效 | 無有效定位 |
| LoRa | `/api/track.rf_alive` 為真：90 秒內接受過綁定 Client 的 DATA／TEL／DIAG／GNSS 任一封包 | 不符合 RF 活動條件 |

- LoRa 綠燈不表示 GPS 有效，也不表示 RF 沒有丟包。GPS 綠燈不表示預期精度一定合格。
- RF 仍活躍但 `linked=false` 時，提示、可存取名稱與資訊頁連線文字顯示「收到遙測，等待 DATA」。
  `linked`／`data_fresh` 保留 5 秒 DATA 門檻，GPS 追蹤另用原有更短的新鮮度 gate；不以遙測延長定位有效期。
  舊 API 缺少 `rf_alive` 時才回退到 `linked`，不把欄位缺漏假造成 RF 成功。
- FPS 由 Station 的接受 DATA 到達時間計算：最近 10,000 ms 包數 ÷ 10；不把網頁輪詢、TEL／DIAG 或拒收包當作 FPS。
  開機前 10 秒分母仍為 10。停止收包後逐筆退出窗口、自然歸零；RF 連線燈與 10 秒 DATA FPS 窗口分開。
  API 欄位為 `lora_fps_10s`；沒有此欄位顯示 `-- FPS`，資料過期時顯示灰燈及「資料過期」。
- 尚無 track 或最後一次成功取得 track 超過 **3 秒**：三燈灰色，顯示「等待資料」或「資料過期」。
  不得長期保留過期綠燈，也不得把瀏覽器失聯直接說成 GPS／LoRa 故障。
- 雷達模式依畫面長寬動態選擇位置及圓心，優先最大化圓圈，同時避開燈號群組與把手。
  直向通常放上方空白，橫向通常放左側空白；接近方形時可移動圓心。
  燈號到外圈保留把手所需間距，不得只按固定直／橫向 CSS 放置而遮住圈。
- 地圖模式固定靠左，上下位置隨畫面高度調整；不能跟著地圖資料漂移。
