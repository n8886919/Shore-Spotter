不再區分待命／深度休眠。電池1,000 mAh，使用者提供有保護板、過充4.2 V／過放2.7 V；尚未量測。

## 行為

- 開機為Ready；每30秒STATE／接收指令，正常空閒保留RAM／boot／Station ownership／序號。
  loop用task notification等待最近期限，nRF52核心的tickless RTC負責SystemON sleep；USER／DIO1使用ISR通知。
  不是SystemOFF重開機。30秒由上一筆STATE TX_DONE起算；確認還需發射／接收／回覆，
  正常約一輪、約31秒，純電池實測30.776秒；失聯仍依65秒命令逾時顯示。
- Tracking維持既有GNSS 2 Hz／最新有效epoch發送，不用長睡眠阻塞UART；Test維持診斷排程。
- 空閒RadioLib `sleep()`（warm-start預設）保留SX1262設定，FEM關閉。下一次TX前明確`standby()`喚醒；TX／RX期間不睡radio；接收無preamble 85 ms，
  有preamble最長800 ms，TX硬期限3秒、FEM後重新讀時鐘。ADC、螢幕及按鍵各自限制等待期限。
- USER短按螢幕5秒；長按2秒放開回Ready。取消待機12小時SystemOFF及正常流程的Storage。
  舊Store API發Stop、期望Ready；舊LoRa Store轉Ready，但舊Station若期待Storage會判error，需更新雙端。
- TFT保留Vext，SLPIN／背光off；不增加650 ms重新初始化阻塞接收。
- ADC健康Ready 30秒，Tracking／Test及<3.5 V警告1秒；三次有效<3.2 V且無USB進低電保護，
  GPS／新RF停止、ADC divider只於取樣開啟、螢幕5秒熄滅。每60秒取樣，三次≥3.5 V回Ready，
  不自動GPS。USB出現與unknown讀值不能單獨解除保護。
- 保護板切斷電源後RTC無法運作；硬體充電／保護解除後重啟回Ready仍待實測。
  韌體不能控制CN3165充電電流或取代保護板。`charging`仍僅USB VBUS。
- Station只改Client卡與相關API，無近期STATE顯示未知；Servo/GPS/UART模式及SD/Axiom設定維持。

## Ready 的一輪具體做什麼（2026-10-10 程式核對）

1. 上一筆 STATE **成功 TX_DONE** 後重新起算 30,000 ms；RAM、boot、指令序號與 Station 控制權保留。
2. Ready 空閒時 GPS load switch 關閉；TFT controller 保持供電但 SLPIN／背光 off；SX1262 warm-start sleep、FEM off。
   loop 以 `ulTaskNotifyTake` 等最近期限，USER／DIO1 IRQ 可提前喚醒，不每輪跑 bootloader。
3. 到 STATE 期限，TX 前先明確 `standby()`，成功才開 FEM／發出 28-byte STATE。
   B 組 SF9／BW125／CR4/5／8-symbol preamble 的計算 airtime 是 **226.304 ms**，不是量得 MCU 清醒時間。
4. TX_DONE 後先聽 **85 ms**；無 preamble/header 就結束，有才等收到封包或最長 **800 ms**。
   Station 有 pending 時等20 ms發一次命令；若服務到此已晚於40 ms，跳過這輪，等下次STATE。
5. 有效 Start 開 GPS、改 Tracking，安排確認 STATE；Stop 回 Ready。Station 比對
   client／boot／station／command／期望 state 才 confirmed。沒有命令則回空閒等待。

健康 Ready 的電池 ADC 也每30秒取樣（RF idle時開divider、等10 ms、平均後關閉），
螢幕／按鍵／電池期限可能讓 MCU 提前醒來。USB存在時單次等待上限20 ms、按鍵處理中5 ms；
低電警告每秒ADC、保護期間每60秒檢查。因此「每30秒交換指令」不代表精確連睡29.7秒，
也不代表 USB接著時可以量到純電池待機電流。Tracking／Test loop等待上限1 ms，並非同樣長睡眠。

無命令的典型radio時序約226 ms TX＋85 ms初始RX，額外有FEM／CPU／ADC等工作；
TX硬逾時3秒與RX最大800 ms是失敗／窗口界線，不是每輪正常耗時。
實際STATE間隔會含下一筆airtime／排程；純電池Start30.776秒才confirmed，不能保證所有命令30秒內完成。
需要實測電池端電流／波形才能計算1,000mAh續航；`blocked_ms`只記task等待。
