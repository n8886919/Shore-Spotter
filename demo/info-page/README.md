# 資訊頁 Demo（2026-10-10）

獨立 HTML/CSS/JS 預覽，沿用現行白底／綠色樣式；此為早期預覽快照；2026-10-11 正式 `include/web_ui.h` 與韌體已整合後續確認內容，以正式頁及 UI 規格為準。
所有值、模式、SD 與串口命令均為模擬。CSP `connect-src 'none'` 禁止連接實機／網路 API，
沒有 fetch、XHR、WebSocket、硬體指令或第三方依賴；不要求手機定位權限、不提供複製摘要。

```sh
python3 -m http.server 8770 --bind 127.0.0.1 --directory demo/info-page
```

開啟 `http://127.0.0.1:8770/`，預設資訊頁。按「← 返回雷達」可預覽完整圓形0～359°指令軌道；
使用者已確認只留手動／GPS。地圖本輪未製作，按鈕停用；位置與波束均為固定模擬示意。

可操作：

- 切換 Ready、Tracking、無 fix、位置過期、RF 失聯、SD 錯誤、無 GPS RF 測試情境。
- Station GPS／手機位置左右切換、手動座標展示（不觸發定位授權）。
- 點速度數字開視窗：整數 1～90，取消／儲存；指南針整數 0～359，預設 90。
- 鏡頭置中展示待驗中位 179.5°與示意脈寬命令，不發送。
- Client 啟動／回待機／RF 測試先 pending，按 Demo 列「模擬收到 STATE」才確認。
  啟動後先顯示 Tracking 無 fix，不把命令確認當定位成功；不切 Station Servo 模式。
- 展開 GNSS、Station／控制板、Client／LoRa 診斷；Ready 的舊 GNSS 快照明示過期。
- 圓形軌道拖曳只預覽，放開才套用本頁值；跨0／359邊界時夾住端點，不環繞。
  0／359在下方、90在左、180在上、270在右，中位約179.5在上；刻度不是地理方位。
  取消手勢／切模式不提交；GPS只保留不可拖曳角度標記，需模擬有效定位才能選。
